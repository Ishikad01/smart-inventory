# 📦 Smart Inventory & Order Management System

A full-stack cloud-based inventory and order management system built with:

- **Frontend:** React.js
- **Backend:** Node.js + Express.js
- **Database:** MongoDB
- **Cloud:** AWS (EC2, S3, VPC, CloudWatch)
- **Containerization:** Docker

## 🚀 Features
- Product inventory management
- Real-time order tracking
- Stock management with auto-reduction
- JWT Authentication
- AWS Cloud deployment
- Docker containerization

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | React.js |
| Backend | Node.js, Express |
| Database | MongoDB |
| Auth | JWT |
| Cloud | AWS EC2, S3, CloudWatch |
| Container | Docker |
